# Phiếu bàn giao

Việc chuyển từ agent này sang agent khác đi qua một phiếu trong thư mục này. Tên file: `<YYYY-MM-DD>-<việc>.md`, viết theo `_MAU-phieu-ban-giao.md`.

- Agent giao điền mục 1–5.
- Thầy mở agent nhận và đưa câu lệnh: `Làm phiếu docs/handoff/<tên file>. Ghi kết quả vào mục "Kết quả" của phiếu.`
- Agent nhận chỉ ghi mục 6, không sửa mục khác.
- Phiếu xong thì đổi trạng thái thành `xong`; không xoá phiếu.
