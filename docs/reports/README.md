# Báo cáo

Kết quả kiểm thử, soát hình, sai số. Tên file: `<YYYY-MM-DD>-<mã>-<loại>.md` với loại là `kiem-thu`, `soat-hinh` hoặc `sai-so`. Số liệu kèm theo lưu dạng JSON hoặc CSV cùng tên để agent sau đọc lại được mà không phải chạy lại.

Mỗi báo cáo ghi: việc được kiểm, cách kiểm, kết quả từng tiêu chí của spec, kết luận `dat` hoặc `can-sua`.
